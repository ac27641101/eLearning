# eLearning

五年級孩子的遊戲化學習網站，用靜態網頁放在 GitHub Pages。

網站：https://ac27641101.github.io/eLearning/

## 單元

- [五年級社會・看見福爾摩沙](social-g5/)

新單元只要把資料夾放進這個專案，再在 `assets/hub.js` 的 `UNITS` 陣列加一張卡片。新頁面請在 `<head>` 引入 `assets/gate.js`（路徑用相對路徑）。

## 獎勵

「看見福爾摩沙」集滿星星可以兌換 Switch 遊戲時間：24 顆星是 1 小時，48 顆星（全部）是 3 小時。拿到的日期會記在這台裝置上。

家長想先看卡片、又不想幫孩子解鎖時，用這兩個網址（只會打開預覽）：

- [1 小時獎勵卡](https://ac27641101.github.io/eLearning/social-g5/?preview=reward1)
- [3 小時獎勵卡](https://ac27641101.github.io/eLearning/social-g5/?preview=reward2)
